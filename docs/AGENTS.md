# AGENTS.md — docs/

Markdown documentation for the patch, tools, and release process.

## Style

- Emoji-led headings, tables over prose.
- 2-space indent (editorconfig).
- Must pass `markdownlint-cli2`.

## Content

- Link to [`manifest.json`](../manifest.json) and scripts rather than duplicating config.
- Keep install/quick-start examples aligned with root [`README.md`](../README.md).
- Per-tool details live in dedicated pages (`llama-cpp.md`, `whisper-cpp.md`, etc.).

## Typos

- New domain words go in [`_typos.toml`](../_typos.toml).
